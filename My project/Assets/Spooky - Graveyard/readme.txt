Spooky - Graveyard I - 3D Game Assets

2015 - Kittens and Elves at Work - http://www.keawstudio.com


This pack contains 11 different models of graves, each one with one or more textures, total of 33 different graves.


=== Files in this pack ===

- Blender and FBX files of each object
- Final textures in PNG format, including Normal textures (folder final textures)
- PNG files with UV Maps (folder uv maps)

- asset file for Unity 3D (version 5.2.1 and above)


=== Structure of the Unity asset file ===

After importing the pack, the structure of folders will be:

- Spooky - Graveyard
	|
	|- folder Additional Files
		|
		| - folder catalog: individual screenshots of each object
		| - folder uv maps: PNG files with UV Mapping
		| - file Source3DFiles.zip: file containing all the Blender source files
	|
	| - Broken Graves: all 3D objects, textures and materials for the broken graves (3 models)
	|
	| - Graves: all 3D objects, textures and materials for the normal graves (8 models)
	|
	| - Prefabs: 33 prefabs of models, with different textures for each model, ready to use.
	|
	| - Scenes: one scene with all the prefabs for demonstrations
